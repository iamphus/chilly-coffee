# Nhạc quán (TV quán)

Đặt file nhạc vào thư mục này (`.m4a`, `.mp3`, `.ogg`, `.opus`, `.webm`). App tự nhận mọi file ở đây,
phát lần lượt theo thứ tự tên file như một đài radio đồng bộ theo đồng hồ (`src/audio/radio.js`).
Tên hiển thị trên nút "Nhạc quán" lấy từ `TRACK_INFO` trong `src/audio/tracks.js` (không có thì là "Bài 1, 2…").

## Nguồn và giấy phép từng bài

| File | Nguồn | Giấy phép |
|---|---|---|
| 1.m4a – 4.m4a | Tự tạo bằng công cụ AI (chủ dự án) | Của chủ dự án; kiểm tra điều khoản của công cụ AI đã dùng trước khi kiếm tiền |

Chỉ thêm nhạc tự tạo, CC0 hoặc CC BY (ghi tên tác giả vào `TRACK_INFO`). Nhạc tải từ YouTube, Spotify… không được đưa lên web.
