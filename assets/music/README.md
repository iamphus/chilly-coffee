# Nhạc quán (TV quán)

Đặt file nhạc vào thư mục này (`.m4a`, `.mp3`, `.ogg`, `.opus`, `.webm`). App tự nhận mọi file ở đây,
phát lần lượt theo thứ tự tên file như một đài radio đồng bộ theo đồng hồ (`src/audio/radio.js`).
Tên hiển thị trên nút "Nhạc quán" lấy từ `TRACK_INFO` trong `src/audio/tracks.js` (không có thì là "Bài 1, 2…").

Các file nhạc **không được commit** (đã có trong `.gitignore`) cho tới khi có giấy phép rõ ràng:
chỉ dùng CC0 hoặc CC BY, ghi tên bài / tác giả / link / giấy phép vào `TRACK_INFO`.
Nhạc tải từ YouTube, Spotify… không được đưa lên web.
